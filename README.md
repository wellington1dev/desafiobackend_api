# desafiobackend_api
Projeto de API de cadastro para Médicos e Dentistas Voluntários
Neste projeto, desenvolvi uma API para cadastro de médicos e dentistas voluntários, simulando o funcionamento de um pequeno sistema de registro de profissionais interessados em participar de ações sociais na área da saúde.

O objetivo do projeto é consolidar e aplicar na prática os principais conceitos aprendidos até o momento utilizando Node.js e Express, explorando a criação de rotas, organização de código e estruturação de uma API.
