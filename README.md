🩺 Médicos e Dentistas Voluntários API

Uma API REST para cadastro de médicos e dentistas voluntários, simulando um pequeno sistema de registro de profissionais interessados em participar de ações sociais e iniciativas comunitárias na área da saúde.

Este projeto foi desenvolvido com o objetivo de consolidar conceitos fundamentais de desenvolvimento back-end utilizando Node.js e Express, aplicando na prática a criação de rotas, organização da estrutura da aplicação e manipulação de dados em uma API.

A proposta simula um cenário simples onde organizações podem registrar profissionais da saúde dispostos a contribuir com atendimentos voluntários em comunidades.

🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

Node.js – Ambiente de execução JavaScript

Express.js – Framework para criação de APIs

JavaScript (ES6+)

Nodemon – Para recarregamento automático durante o desenvolvimento

Insomnia / Postman – Para testes de endpoints da API

📦 Instalação

Clone o repositório:

git clone (https://github.com/wellington1dev/desafiobackend_api)

Entre na pasta do projeto:

cd desafio_backend

Instale as dependências:

npm install

▶️ Como Rodar o Projeto

Para iniciar o servidor em modo de desenvolvimento:

npm run dev

Ou:

node server.js

O servidor será iniciado em:

http://localhost:3000
📡 Endpoints da API
📋 Listar todos os voluntários
GET /volunteers
